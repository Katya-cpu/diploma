# Платёжный помощник — расширение и стенд проверок

Ветка `extension-only`: только браузерное расширение и лаборатория проверок. Исследования графа транзакций
(модели, датасеты, учебник GraphSAGE) в этой ветке нет — оно лежит в ветке `rewrite-v2`.

Расширение Firefox **перед оплатой** проверяет страницу и объясняет, кому на самом деле уйдут деньги:
15 видов мошенничества с реальными случаями и снимками работы расширения на настоящих страницах (898 страниц из urlscan.io,
Zenodo 14880589, Phish360 и E-Skimming Labs) и 17 проверок (20 правил анализатора), которые их ловят;
каждая проверка работает в одной или нескольких схемах.

## Запуск на любом компьютере

Нужны только Python 3.10+ и Firefox. Дополнительные библиотеки для стенда не требуются.

1. Скачайте ветку:
   `git clone -b extension-only --single-branch https://github.com/Katya-cpu/diploma.git`
2. Запустите `Открыть лабораторию.cmd` (или `python server.py`) — откроется http://127.0.0.1:8765/
3. В Firefox: `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение…» → файл `extension/manifest.json`.
4. В лаборатории откройте «Проверки», выберите проверку и нажмите «Открыть отдельно (для расширения)».

## Что где лежит

| Папка | Что в ней |
|---|---|
| `extension/` | расширение: `core/checks.js` — все правила анализатора, `core/catalog.js` — описание проверок (признаки, классификация MITRE), `core/schemes.js` — виды мошенничества и реальные случаи, `content.js` — панель на странице, `background.js` — наблюдение за запросами |
| `lab/checks.html` | раздел «Мошенничество и проверки»: виды мошенничества с реальными случаями; у проверок — описание, тестовые страницы, запуск анализатора, полный список признаков, «как увидеть самому» |
| `lab/scenarios/` | тестовые страницы, оформленные как настоящие сайты |
| `lab/pages/` | короткие тестовые страницы, в том числе честные (на них расширение должно молчать) |
| `lab/eval*` | оценка «было / стало» на настоящих страницах (для повторного прогона нужен набор Phish360, в репозитории его нет) |
| `docs/` | ТЗ, руководства, [обоснование проверок и сверка классификации](docs/scenario-evidence.md), [результаты оценки](docs/eval-results.md) |
| `tools/` | генераторы тестовых страниц и QR-кодов, `firefox_check.py` — автоматическая проверка расширения в Firefox |

## Как убедиться, что всё работает

- http://127.0.0.1:8765/checks.html?autorun=1 — прогон всех 46 тестовых страниц; должно быть «Совпало 46 из 46».
- `python tools/firefox_check.py` — запускает отдельный Firefox с расширением и сохраняет снимки страниц с панелью
  помощника в `tools/firefox-shots/` (нужна библиотека `websockets`: `pip install websockets`).

Все сайты, люди и реквизиты на тестовых страницах вымышлены; адреса «злоумышленника» лежат в зоне `.invalid`
и не существуют. Расширение предупреждает, но не блокирует и не гарантирует безопасность.
