# Платёжный помощник

Учебный проект (ВКР): браузерное расширение, которое **перед оплатой** проверяет страницу и объясняет, кому на самом деле
уйдут деньги, — и исследование оценки риска счёта-получателя по графу банковских переводов.

## Три части

1. **Проверки страницы** — 14 проверок в расширении Firefox. Каждая отвечает на задокументированную схему мошенничества
   («Мамонт», веб-скимминг Magecart, подменённые QR-коды, «безопасный счёт», кликджекинг…). Обоснование: [docs/scenario-evidence.md](docs/scenario-evidence.md).
2. **Учебные сценарии** — 12 реалистичных страниц (10 мошеннических, 2 честных) для испытания расширения.
3. **Граф транзакций** — синтетический банк IBM AMLworld (5 млн переводов), сравнение правила, логистической регрессии,
   градиентного бустинга и графовой нейросети GraphSAGE; имитация перевода с оценкой риска получателя.

## Быстрый старт

1. `Открыть лабораторию.cmd` → http://127.0.0.1:8765/
2. Firefox → `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» → `extension/manifest.json`
3. Для графа: один раз `Установить ML.cmd`, затем в разделе 3 кнопки «Скачать датасет» → «Построить граф» → «Обучить модели».
