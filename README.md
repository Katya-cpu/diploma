# Учебный прототип: платёжная безопасность

При получении с GitHub скачайте `payment-guard-work-in-progress.zip` и распакуйте его в отдельную папку: полная структура проекта находится внутри архива. Этот файл README также находится в архиве. Текущая загрузка через GitHub содержит архив; исходные файлы пока не опубликованы отдельным деревом.

Это разрабатываемая учебная сборка, не готовый защитный продукт. Отдельный анализатор применяет понятные правила к доступным наблюдениям; лаборатория содержит учебные случаи и имитацию решения по истории. Никакой банк не подключён, реальные переводы не выполняются. Есть экспериментальный код графовой модели, OCR и статического анализа скриптов, но они не интегрированы в расширение, не обучены и не проверены. Ручной разбор QR ограничен поддерживаемыми форматами.

## Как открыть лабораторию

Дважды нажмите `Открыть лабораторию.cmd`. Нужен Python 3; окно командной строки должно оставаться открытым. В браузере откроется http://127.0.0.1:8765/ . Для остановки нажмите Ctrl+C в окне командной строки. Введите только фиктивные данные.

Лаборатория включает ручной текст, QR, OCR, простой имитатор получателя, сценарии перекрытия и изменения формы, пассивный анализ учебного JavaScript, историю и экспериментальные модели. Некоторым разделам нужны дополнительные локальные компоненты: см. `docs/developer.md` и `research/README.md`. Модель и экспериментальные результаты не поставляются готовыми. Эти дополнения в текущем ходе не запускались по просьбе заказчика.

## Учебное расширение Firefox

В Firefox откройте `about:debugging` → «Этот Firefox» → «Загрузить временное дополнение» и выберите `extension/manifest.json`. Перейдите к отдельной учебной странице из лаборатории. Временное дополнение удаляется при закрытии Firefox. Расширение не проверялось в Firefox на этом компьютере, поскольку установленный Firefox в обычных папках не обнаружен; перед использованием его необходимо установить и проверить. Предупреждение не блокирует передачу данных и не гарантирует защиту.

## Разработчику

`shared/analyzer.js` — правила; копия в `extension/analyzer.js` необходима для загрузки браузером. `extension/content.js` преобразует доступные признаки DOM в наблюдения. `lab/` — интерфейс и тестовые случаи; `start_lab.py` отдаёт его только на localhost; `research/` — исследовательские скрипты. При изменении правил нужно обновить копию в расширении. Имитатор `shared/bank.js` рассматривает только учебные переводы до момента заявки и применяет простые правила; это не обученная банковская модель. Искусственные метки сценариев в классификатор не передаются.

Расширение хранит локальные исключения по точному origin сайта и не отключает ими предупреждения о найденных признаках угроз. Изменения в этой сборке пока не проверены: пользователь попросил провести испытания на другом компьютере.

Документы `docs/product.md`, `docs/user.md`, `docs/developer.md` — рабочие черновики; их нужно обновить после завершения реализации и испытаний. Карта отсутствующих и частично реализованных функций — `docs/implementation-status.md`. Актуальный объём — `../outputs/technical-specification.md`; то, чего в этой сборке нет, не считать реализованным.
