# Платёжный помощник

Учебный проект (ВКР): браузерное расширение, которое **перед оплатой** проверяет страницу и объясняет, кому на самом деле
уйдут деньги, — и исследование оценки риска счёта-получателя по графу банковских переводов.

## Две части

1. **Проверки страницы** — расширение Firefox. Перед оплатой оно отвечает на семь вопросов человека: куда уйдут введённые
   данные, кому уйдут деньги, сколько спишут, что делает код страницы, давят ли на вас, просят ли запустить команду
   и подключить криптокошелёк. Лаборатория описывает **6 схем мошенничества** (поддельная страница оплаты или входа в банк,
   перевод мошеннику, подписочная ловушка, скиммер, ClickFix, криптодрейнер), **11 видов подачи** и **7 проверок**
   с полным списком сообщений панели (44); у схем и подач — настоящие страницы и снимки работы расширения на них,
   каждая проверка работает в одной или нескольких схемах. Решение принимается по совокупности
   признаков и с учётом контекста (есть ли на странице что-то, ведущее к деньгам; кем представляется сайт; что реально уходит в сеть).
   Обоснование и номера MITRE CAPEC / ATT&CK / F3: [docs/scenario-evidence.md](docs/scenario-evidence.md);
   сравнение с прежней версией на настоящих страницах: [docs/eval-results.md](docs/eval-results.md).
   В разделе «Проверки» лаборатории у каждой проверки: реальные случаи, тестовые страницы (52 штуки, включая честные),
   полный список признаков правила и способ увидеть нарушение самому, без помощника.
2. **Граф транзакций** — синтетический банк IBM AMLworld (5 млн переводов), сравнение правила, логистической регрессии,
   градиентного бустинга и графовой нейросети GraphSAGE; имитация перевода с оценкой риска получателя.
   Пояснение для начинающих — учебник [lab/graphsage.html](lab/graphsage.html) (открывается и без сервера).

## Быстрый старт

1. `Открыть лабораторию.cmd` → http://127.0.0.1:8765/
2. Firefox → `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» → `extension/manifest.json`
3. Для графа: один раз `Установить ML.cmd`, затем в разделе «Граф транзакций» кнопки «Скачать датасет» → «Построить граф» → «Обучить модели».
