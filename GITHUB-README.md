# Учебный проект: платёжный помощник — рабочий снимок

В архиве `payment-guard-work-in-progress.zip` находятся исходные файлы расширения Firefox, локальная учебная лаборатория, простые исследовательские инструменты и техническое задание. Распакуйте архив и прочитайте `product/README.md`.

**Проект в разработке. Это не законченная дипломная работа и не средство, проверенное для реальных платежей.** Изменения после 29 октября 2026 года не проверялись по просьбе заказчика; испытания необходимо выполнить на другом компьютере. Большие внешние датасеты в архив не входят; сведения об их источниках приведены в `product/research/`.

Это снимок исходных файлов, загруженный через веб-интерфейс GitHub, пока настройка командного доступа Git остаётся незавершённой.
