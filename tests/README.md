# Проверки на другом компьютере

Эти проверки подготовлены, но не запускались в текущем ходе по просьбе заказчика. Установите Node.js и запустите `node tests/analyzer.cjs` из папки product. Это проверяет несколько правил, но не работу WebExtension и не является оценкой качества модели.

Затем откройте лабораторию, переключите каждый сценарий и проверьте экспорт журнала и очистку. В Firefox загрузите временное дополнение, проверьте уведомление о карточной форме, повторный анализ кнопкой расширения и сохранение исключения только для одного origin. Проверьте отсутствие реальных данных в файлах результатов. Отдельно проверьте, что изменившийся платёжный контекст снова вызывает уведомление об угрозе и что защищённые вкладки/недоступные iframe описываются как ограничение. Для модели запустите инструкции из `research/README.md` и сохраните фактические выходные метрики отдельно.
