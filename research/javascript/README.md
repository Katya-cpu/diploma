# Пассивный анализ JavaScript

На другом компьютере: `npm install`, затем `node inspect.js путь-к-файлу.js`. Парсер строит AST и перечисляет некоторые сетевые вызовы, обращения к DOM и вставки HTML, не исполняя код сайта. Признаки не доказывают кражу или эксплуатацию XSS. Охват зашифрованных, динамических и обфусцированных скриптов ограничен. В `train_model.py` находится код обучения простой модели на заранее извлечённых и размеченных AST-признаках, но размеченный корпус скриптов не собран и модель не обучена. Подключения к расширению нет.

Лаборатория принимает вставленный код. Если Node.js или зависимости отсутствуют, она использует простой поиск текста: он не строит AST и может принимать комментарии и строки за код. Для AST установите Node.js, откройте PowerShell в папке `research/javascript` и выполните `npm install`, затем перезапустите лабораторию. Если локально обучить модель и сохранить её в `research/javascript/model/js-model.joblib`, AST-разбор дополнительно покажет гипотезу; иначе вернётся «неизвестно». Не загружайте модели из недоверенных источников: формат joblib допускает исполнение кода при загрузке.
