# Состояние реализации относительно ТЗ

Это перечень реализации по исходному коду, а не результаты проверок. Пользователь разрешил локальные испытания; ниже перечислены возможности и ограничения, а результаты конкретных проверок описаны отдельно. Реализация не готова к использованию на реальных оплатах.

| ID | Состояние | Что есть и чего не хватает |
|---|---|---|
| F01 | Частично | Фоновый набор правил; контекстная модель не встроена. |
| F02 | Частично | Поиск поля и уведомление после загрузки документа; гарантии и барьера до ввода нет. |
| F03 | Частично | Подписи кнопок и текст; обнаружение HTTP-адреса в прямой платёжной ссылке. Сравнение намерения и фактического назначения ограничено; сценарии через скрипты и перенаправления не устанавливаются. |
| F05 | Частично | Лаборатория применяет локальный jsQR и резервный ZXing; расширение — jsQR к доступным изображениям. Сравнение поддерживается для части форматов; личность получателя не устанавливается. Формат СБП распознаётся ориентировочно без проверки регистрации. |
| F06–F08 | Частично | Простейшие русские текстовые сигналы и маскирование; извлечение и сопоставление далеко не полные. |
| F11 | Частично | Исключение на точный origin верхней страницы и список для удаления; обычные предупреждения во фреймах не отключаются. Поведение не проверено. |
| F12 | Частично | Простые категории и причины; обученной калиброванной оценки нет. |
| F13 | Частично | Текст лаборатории и QR-строки; отдельный CLI OCR, не встроен в приложение; ссылки анализируются ограниченно. |
| F14 | Частично | События текущей вкладки в памяти, без значений; изменения сценария не сопоставляются полноценно. |
| F15 | Частично | Общее правило ищет ограниченные сочетания текста во встроенных скриптах доступной карточной страницы; внешние и скрытые скрипты не проверяются. Отдельный AST-инспектор в лаборатории; обученной модели в расширении нет. |
| F16 | Частично | Фокус и события изменения выбранных полей в памяти; не определяет чтения скриптами. |
| F17 | Частично | Наблюдаются origin после обнаружения платёжного контекста; запросы не блокируются, содержимое и источник-скрипт неизвестны. |
| F18–F19 | Частично | Проверка перекрытия центра доступного поля и почти прозрачных активных элементов с платёжным описанием. Визуального сравнения нет; признаки не доказывают кликджекинг и обнаруживают не все случаи. |
| F20 | Частично | Отдельный статический поиск некоторых операций AST; уязвимость не подтверждает. |
| F21 | Частично | По запросу пользователя считаются некоторые атрибуты cookies для корня текущего сайта; через API значения временно поступают в память, но не сохраняются; остальные пути и безопасность сессии не оценены. |
| F24 | Частично | Объяснение видов разрешений; фактические запросы браузера не перехватываются. |
| F29 | Частично | Локальный CLI и кнопка в лаборатории для GGUF; не встроен в расширение, модель не поставляется. |
| F30 | Частично | Регулярные выражения и код обучения CRF/трансформера; размеченного корпуса, обученных весов и подключения нет. |
| F31 | Частично | OCR CLI и локальная загрузка изображения в лаборатории; сопоставление с DOM и подключение OCR к расширению отсутствуют. |
| F32 | Частично | Код обучения текстового классификатора и локальная гипотеза в лаборатории; калибровка и подключение к расширению отсутствуют. |
| F34 | Частично | Есть сравнение базовых моделей и GraphSAGE с временными срезами, параметры и порог. 30.10.2026 выполнен учебный запуск на собственных синтетических данных (15 эпох, 4 положительных тестовых случая). Независимой оценки на мошеннических покупках нет. |
| F35 | Частично | Проверки страниц и симуляция графа по запросу пользователя разделены; связь с банком отсутствует. Графовая гипотеза выдаёт только учебное решение по порогу. |
| F39 | Частично | Ручные сценарии, пакетная проверка искусственных примеров и тестовые скрипты; нет полного набора атак и независимой оценки реальных страниц. |
| F40 | Частично | Краткий локальный журнал предупреждений расширения и учебной лаборатории, JSON и очистка; пользовательские сценарии экспорта не полные. |
| F42 | Частично | Рекомендации по трём типам события в лаборатории и памятка в расширении; автоматической связи с банком и полного сценария инцидента нет. |

ТЗ остаётся источником требований. Ни одно из перечисленных частичных состояний не должно быть представлено как доказанное соответствие требованиям или как готовый диплом.

Проверки личных данных: распознаются некоторые поля имени, телефона и почты по атрибутам без чтения значений; это информационное уведомление, не доказательство угрозы и не контроль передачи.
