# Руководство пользователя

## 1. Открыть лабораторию

1. Дважды щёлкните `Открыть лабораторию.cmd` (нужен Python 3). Откроется http://127.0.0.1:8765/.
2. Чёрное окно не закрывайте — это сервер. Остановить: закрыть окно или Ctrl+C.
3. Для раздела «Граф транзакций» один раз запустите `Установить ML.cmd` (скачает ~300 МБ библиотек).

## 2. Установить расширение в Firefox

1. В Firefox откройте `about:debugging#/runtime/this-firefox`.
2. «Загрузить временное дополнение…» → выберите `product/extension/manifest.json`.
3. На панели появится значок щита. Временное дополнение удаляется при закрытии Firefox.

## 3. Что показывает расширение

На странице с оплатой или переводом в правом нижнем углу появляется панель:

- **Высокий риск — не платите** (красный) — найден признак, характерный для мошенничества;
- **Есть подозрительные признаки** (оранжевый) — стоит перепроверить;
- **Явных признаков обмана не найдено** (зелёный) — это не гарантия безопасности.

Под итогом — какие признаки найдены и **кому уйдут деньги** (карта, телефон или счёт и чей он: частного лица или организации).
Кнопка расширения на панели браузера открывает подробности: почему сработала проверка и откуда она взята, что проверить не удалось, журнал предупреждений.

«Доверять этому сайту» скрывает обычные уведомления только для этого сайта. Предупреждения об угрозах показываются всегда.

## 4. Лаборатория

- **1 · Проверки** — каталог 14 проверок. Выберите проверку слева: описание, тестовая страница и кнопка «Запустить анализатор». На страницах с формой карты нажмите «Ввести тестовую карту». «Прогнать все тестовые страницы» — сводная таблица.
- **2 · Сценарии** — реалистичные мошеннические страницы. Откройте их в Firefox с расширением.
- **3 · Граф транзакций** — «Как это работает» (объяснение), «Модель и обучение» (кнопки 1–2–3 и параметры), «Имитация перевода» (выберите пример счёта и нажмите «Отправить перевод на проверку»).

Вводите только тестовые данные. Все сайты, люди и реквизиты на учебных страницах вымышлены.
