# Разработчик: рабочая инструкция

## Устройство

`extension/` — Firefox WebExtension; `shared/analyzer.js` — независимая логика правил, его копия лежит в расширении; `shared/payment-details.js` — минимальный разбор QR-строк и сопоставление сумм; `shared/bank.js` — учебный оценщик истории. `lab/` — локальные HTML-сценарии; `start_lab.py` отдаёт их на 127.0.0.1. `research/` содержит генерацию учебного графа, описание SynSEPA, эксперименты моделей, необязательный локальный языковой анализ и AST-анализ файлов JavaScript. Секреты и фактические введённые значения не требуются для классификации.

## Запуск на другом компьютере

Для лаборатории достаточно Python 3. Для исследования моделей установите пакеты из `research/requirements.txt` в отдельное виртуальное окружение. Из папки product выполните `python research/generate_demo.py`, затем `python research/train_models.py --input research/demo_data/transactions.csv --output research/results`. Результаты сохраняются только после фактического запуска. Для текстового классификатора нужны собственные размеченные `train.csv` и `test.csv` с полями `text,label`, разнесённые по источникам и времени; команда описана параметрами `--help`. Для локального LLM нужны llama-cpp-python и самостоятельно выбранная модель GGUF; `local_context.py --help`. AST-анализ использует Node.js и зависимости в `research/javascript/`.

OCR в лаборатории дополнительно требует Pillow, pytesseract и установленную локальную программу Tesseract с данными языков rus и eng. Изображение передаётся только локальному серверу в памяти, до 2,5 МБ; автоматическое скрытие числовых реквизитов может ошибаться, поэтому использовать только учебные изображения. Если компоненты отсутствуют, показывается состояние «неизвестно».

Эксперименты имеют ограничения, описанные в `research/README.md` и выводе `metrics.json`: особенно важны отсутствие заявлений о реальном качестве и недопущение использования будущих данных. `joblib` и файлы моделей следует загружать только из доверенных источников.

При изменении `shared/analyzer.js` скопируйте его в `extension/analyzer.js`; то же относится к `payment-details.js`. Готовой сборочной системы нет. В `tests/` подготовлены проверки для запуска на другом компьютере и инструкция по ручной проверке браузерного поведения. Проект и инструкции не проверялись в текущем ходе: заказчик перенёс проверку на другой компьютер. Документация не является подтверждением успешного запуска.
