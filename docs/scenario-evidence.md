# Источники учебных сценариев и границы выводов

Учебные страницы синтетические: они не являются архивными копиями настоящих мошеннических сайтов и не могут служить доказательством частоты атак. Источники ниже подтверждают соответствующий класс угроз; конкретную комбинацию полей, формулировок и стилей в стенде создали для испытания правил.

|---|---|---|---|
| Поддельная страница оплаты / получения денег в маркетплейсе | [ESET, Telekopye: Hunting Mammoths](https://www.welivesecurity.com/en/eset-research/telekopye-hunting-mammoths-using-telegram-bot/); [ESET, Chamber of Neanderthals’ secrets](https://www.welivesecurity.com/en/eset-research/telekopye-chamber-neanderthals-secrets/) | Шаблонные фишинговые сайты и сценарии продавца/покупателя, запрос карточных данных для якобы получения средств. | Нельзя считать каждую учебную формулировку дословным воспроизведением Telekopye или использовать статью как частоту конкретного признака. |

## Как читать доказательства

Сначала фиксируется наблюдаемое действие из источника и контекст. Затем разрабатывается искусственная страница, имитирующая соответствующую поверхность атаки. После этого проверяется, какие из её признаков действительно доступны расширению. Механизм совпадения признака и конкретная атака — не одно и то же. Для дипломной оценки нужны независимые страницы, сведения о происхождении и разметке, отрицательные примеры, ложные предупреждения и разделение по источникам/времени.

## Данные транзакционного графа

[SynSEPA](../research/synsepa-audit.md) изучен, но по текущему аудиту только небольшая часть мошеннических получателей связана с несколькими отправителями; набор слаб для основной задачи множества отправителей на одного получателя. В проекте доступен синтетический Misata AML как отдельный независимый пример, а собственный генератор — как контролируемый стенд. Ни тот ни другой не доказывает эффективность на пострадавших от интернет-мошенничества. Выбор референтного набора для научного вывода остаётся открытым; нельзя переименовать AML-метки в метки «Мамонт».
